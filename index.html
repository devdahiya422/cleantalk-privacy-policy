Privacy Policy

Last updated: September 2026

CleanTalk ("the Bot") is a Discord moderation bot that automatically filters inappropriate language and spam in servers where it is added. This Privacy Policy explains what data the Bot collects, how it is used, and your rights regarding that data.

Information We Collect

When added to a server, the Bot may process the following data strictly to provide its moderation features:

  • Message content: Messages sent in text channels are scanned in real time to detect filtered words or spam patterns. Messages that do not violate server rules are not stored.
  • User IDs: Used temporarily to track spam patterns (e.g., message frequency) and to send direct message notifications when a message is removed.
  • Server configuration: Filtered word lists and moderation settings (such as spam limits and notification preferences) configured by server administrators are stored so the Bot can apply them consistently.

How We Use Information

Data collected is used only to:

  • Detect and remove messages containing filtered words or spam.
  • Notify the relevant user when their message is removed (if enabled by server administrators).
  • Maintain moderation settings and filtered word lists per server.

Data Storage

Moderation settings and filtered word lists are stored in plain configuration files on the hosting service running the Bot. No message content, personal messages, or user profile information is permanently stored. Data related to spam-pattern tracking (such as recent message timestamps) is kept in memory only and is cleared when the Bot restarts.

Data Sharing

We do not sell, rent, or share any collected data with third parties. Data is used exclusively to operate the Bot's moderation features.

Your Rights

Server administrators may remove the Bot from their server at any time, which stops all data collection for that server. Users may contact the server administrator to request removal of any specific configuration data related to them.

Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of the Bot after changes are posted constitutes acceptance of the updated policy.
